# Ace2 RAG 第二轮：引用体验、关键词兜底与检索评测

日期：2026-10-06。接续 `ace2-rag-optimization.md`。本轮只修改代码、运行本地测试和构建；未安装或重启手机应用，未同步或清空知识库，未改变 CPU/GPU、线程或量化参数。

## 交付

- 完成后的回答保留 `[1]` 等可见引用编号，点击打开该回答对应的原文章节。编号按引用 ID 解析，不按面板下标解析；多个编号合并到同一章节、同名文档仍正确映射。只处理答案显示文本，代码、现有链接、原文与朗读文本不改写。
- 原文改为单章节底部阅读面板。聊天中只展开来源标题，面板支持切换章节、复制原文、逐个复制代码块、打开 Obsidian。生成首 token 前即可查阅已经检索到的资料；不在聊天里同时解析全部长章节。
- 显示检索、生成未核对草稿、引用核对阶段，以及检索方式、命中数、检索耗时。无命中时标明本轮未引用知识库。取消与异常会结束等待状态；取消的 RAG 草稿标为引用未核对，不自动朗读，也不显示手动朗读入口。资料和 RAG 答案继续排除在意图执行链路外。
- 关键词检索不再依赖 Embedding 成功。模型缺失、计算返回空、可恢复的初始化异常、向量维度不一致时，仍可检索**已经存在的 SQLite 原文**。不捕获协程取消，不捕获内存耗尽等虚拟机致命错误。
- 新增内存倒排索引：英文技术名/包名精确匹配、限定名 API 的组成词、中文双字短词，以及标题/章节加权的 BM25 式评分。多英文锚点需要完整覆盖；若有标题/章节完整匹配的主题，关键词候选优先限定到这些主题，减少同名词在无关笔记里的偶然提及。向量候选仍保留独立召回能力。
- 关键词结构和向量有效性随知识库同步时间一起缓存，用原子快照替代分离的缓存状态。不修改数据库 schema，不要求重新同步。查询时不再全量转小写、运行逐篇关键词正则或全量排序；保留最多 8 个结果、每篇最多 2 个的约束。
- 原文复制使用现有 Compose 版本的 Clipboard 接口；Android 13+ 标为敏感剪贴板内容，避免系统复制预览暴露笔记。Markdown 结构解析器直接固定为现有 richtext 所用的 CommonMark 0.21.0。

## 验证

先提取生产检索的可测试入口，保留旧行为并添加失败回归：10 个测试中 6 个失败，覆盖 Embedding 缺失/异常、维度不一致、引用链接转换。修复后又捕获“Apache Hive 正文提到 Flutter，导致作为额外来源”的关键词尾部误召回，再补主题字段约束。

76 项 JVM 测试通过，`:app:assembleDebug` 成功。包含原有回归、引用代码/链接/转义/CRLF 保护、代码复制、中断草稿状态、取消传播、中文与包名检索、150 组有文档数量约束的排序对照。

额外运行 `:app:lintDebug`：发现 2 个错误、83 个警告，未全量通过。两个错误都来自本轮未修改的 Manifest 权限声明（缺少可选 camera feature、`QUERY_ALL_PACKAGES` 的应用可见性声明），已确认 HEAD 中同样存在。未为使检查变绿而移除权限或隐藏检查；不影响本轮 APK 构建，但发布前应单独处理。新 RAG 检索/引用/复制代码未出现 lint 错误。

`app/src/test/resources/rag/retrieval-questions.tsv` 提供 24 个固定问题，覆盖用户原始 Hive 问法、API、中文主题、Flutter/Apache 同名歧义、无资料及虚构包名，受控资料库中 **24/24** 符合预期。另有检索 → 提示词 → 引用核对 → 原文代码的串联测试。这不是用户真实知识库的命中率，也不是 2B 模型的生成正确率评测。

桌面 JVM 合成对照（18,679 分块、512 维、同一问题，预热后 7 次中位数）：

| 项目 | 耗时/体积 |
|---|---:|
| 旧逐篇词法扫描与全量排序 | 377.4 ms |
| 新缓存关键词索引与有界结果选择 | 12.5 ms |
| 新索引首次构建 | 570.7 ms |
| 关键词索引 primitive 数组 | 2,903,004 bytes |

以上不含模型 Embedding 的真实计算、SQLite 初次读库和章节扩展；数组体积不含字符串、Map/对象开销、原文及向量。首次索引构建有成本；这是合成资料、电脑 JVM 的结果，**不能推导手机首字时间、内存峰值或 token/s 提升**。

## 复现

```sh
./gradlew :app:testDebugUnitTest :app:assembleDebug --console=plain
```

单独重跑固定问题与检索性能对照：

```sh
./gradlew :app:testDebugUnitTest --tests 'cn.xxstudy.assistant.rag.RagRetrievalEvaluationTest' --tests 'cn.xxstudy.assistant.rag.RagSearchBenchmarkTest' --console=plain
```

## 真机验收与后续

待允许覆盖安装测试 APK 后，保留原聊天、模型与知识库，验证点击引用、章节切换、代码复制、返回聊天滚动位置、生成中查原文、语音及打断；对照实际知识库的冷/热检索耗时、额外内存、首字等待和引用回退率。不要运行可能卸载应用或清空数据的 instrumentation runner。

本轮尚未做精确 token 分块（Embedding 512-token 截断仍需后续解决）、按问题挑选资料中的关键片段、逐文档同步版本/失败续传、语义 reranker、ANN 或系统提示 KV 复用。中文双字短词不是完整分词器，混合检索规则与关键词主题限制仍需用真实资料评估误召回/漏召回；引用校验仍是保守字符串规则，不是语义真实性证明。
