<reference id="1" note="Hive.md" section="介绍">
[笔记: Hive > 介绍]
Hive 是轻量级键值数据库，通过 Box 保存数据，适合本地设置和缓存。
```dart
await Hive.initFlutter();
final box = await Hive.openBox('settings');
await box.put('theme', 'dark');
final theme = box.get('theme');
```
</reference>

